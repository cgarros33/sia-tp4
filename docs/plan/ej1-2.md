3. **Preprocessing:** z-score standardization with sample standard deviation (`ddof=1`), fitted on the training data (all 50 in this case). Outliers are retained.

4. **Grid distance:**

   - `euclidiana` is the default BMU criterion.

11. **Reproducibility:** 3 seeds (`[0, 1, 2]`), same seeds across all sweep candidates, mean ± sample std. Final figures use the seed whose QE is closest to the mean; the chosen seed is recorded.

## 5. Model

### 5.1 Architecture and training

- Online SOM: one input record per iteration, shuffled epochs.
- Input dimension `D = 27`.
- Output grid `k × k`, rectangular or hexagonal.
- BMU:
  - `euclidiana`: `k̂ = argmin_j ||z_p − w_j||₂`.
  - `exponencial`: normalize `z_p` and each `w_j` to unit norm, then `k̂ = argmax_j exp(-||z̃_p − w̃_j||²)`.
- Grid distance:
  - Rectangular: Euclidean. `R = 1` → 4 neighbors; `R = sqrt(2)` → 8 neighbors.
  - Hexagonal: cube distance; `R = 1` → 6 neighbors.
- Neighborhood:
  `N_k(t) = { j : d_grid(j, k̂) <= R(t) }`.
- Kohonen update:
  `w_j ← w_j + η(t)(z_p − w_j)` for `j ∈ N_k(t)`; unchanged otherwise.
- Initialization:
  - `uniforme`: per-feature uniform in `[min, max]` of the training data.
  - `muestras`: random training samples with replacement.
- Separate RNG streams for initialization and sample order, both derived from the seed, so the same seed gives the same sample order even when the initialization method changes.
- BMU search and weight updates are vectorized over neurons. Evaluation is vectorized over samples. The per-sample loop is kept because the algorithm is inherently online.

### 5.2 Schedules

- Radius: `R(0) = R0`, `R(T−1) = R_f = 1.0`.
  - `constante`: `R(t) = R0`.
  - `lineal`, `exponencial`, `inversa` (smoothed `1/t` family reaching `R_f`).
- Learning rate: `η(0) = η0`, `η(T−1) = η_f = 0.001`.
  - `lineal`, `exponencial`, `inversa`.
- `T` is the total number of updates; the script prints the equivalent number of epochs (`T / 50`).

### 5.3 Metrics

- **QE** (primary): mean Euclidean distance from each sample to its BMU.
- **TE**: fraction of samples whose second BMU is not an immediate grid neighbor of the first.
- **Dead units**: neurons with zero wins.
- **Occupancy**: fraction of neurons with at least one win.
- **Local QE per neuron**: mean distance of the samples assigned to that neuron; empty neurons use `NaN`.

### 5.4 U-matrix

For each neuron `j`:

`U_j = mean(||w_j − w_l||₂)` over the immediate grid neighbors `l` of `j`.

- Rectangular: 4 immediate neighbors.
- Hexagonal: 6 immediate neighbors.
- Border and corner neurons use the available neighbors.
- High values indicate large weight differences between adjacent neurons; low values indicate homogeneous regions.
- The U-matrix is not defined in pp. 121–124; this standard definition is recorded in `docs/decisiones.md`.

## 6. Hyperparameters and sweep protocol

### 6.1 Swept hyperparameters

The grid is fixed per full sweep: `grillas_fijas = [3, 4, 5]`, i.e. 9, 16 and 25 neurons. For each fixed `k`, the sequential order is:

1. `topologia`
2. `distancia`
3. `inicializacion`
4. `radio_inicial_relativo`
5. `decaimiento_radio`
6. `eta_inicial`
7. `decaimiento_eta`
8. `iteraciones`

| # | Hyperparameter | Candidates | Neutral | Rationale / plausible region |
|---|---|---|---|---|
| — | `grillas_fijas` | `3, 4, 5` | — | Fixed per full sweep. Large `k` produced QE 0 and many dead neurons, so it is not a valid optimization target. |
| 1 | `topologia` | `rectangular, hexagonal` | `rectangular` | Both are allowed by the theory; rectangular is the simpler baseline. |
| 2 | `distancia` | `euclidiana, exponencial` | `euclidiana` | Euclidean is the default; exponential is implemented as the normalized-vector variant. |
| 3 | `inicializacion` | `uniforme, muestras` | `muestras` | Samples usually reduce dead units; uniform is the theory’s first option. |
| 4 | `radio_inicial_relativo` | `0.3k, 0.4k, 0.5k, 0.75k, 1.0k, 1.5k` | `0.5k` | Se agregaron 0.3k y 0.4k para explorar radios iniciales más chicos. |
| 5 | `decaimiento_radio` | `constante, lineal, exponencial, inversa` | `lineal` | Linear/exponential are standard; constant is allowed by the theory; inverse decays fast. |
| 6 | `eta_inicial` | `0.01, 0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 0.9` | `0.5` | Typical 0.1–0.5; extremes test under/over-plasticity. |
| 7 | `decaimiento_eta` | `lineal, exponencial, inversa` | `lineal` | Linear/exponential are standard; inverse decays fast. |
| 8 | `iteraciones` | `5000, 10000, 15000, 25000` | `10000` | The new range keeps the runs shorter. Editable in the config. |

### 6.3 Sequential selection

The same sequential procedure is repeated once for each fixed `k` in `[3, 4, 5]`.

At each step:

1. Set the current neutral value for the parameter being swept.
2. Keep all other parameters at their current adopted values.
3. Include the current adopted value in the candidate set.
4. Train every candidate with seeds `[0, 1, 2]`.
5. Compute mean ± sample std of QE.
6. Select the minimum mean QE for every parameter.
7. Update the neutral value with the selected value.
8. Save the step CSV and step figure.
9. Continue with the next parameter.

The 5% elbow and `grilla` exception no longer exist; `grilla` is fixed per sweep and rejected from the sequential order.

If the selected value is at the edge of its candidate list, print a warning and record it in `registro.txt`. Extend the candidate list in the TOML and rerun that step; no code change is required.

### 6.4 Strong couplings after the sequential sweep

After the full sequential sweep:

1. Start from the sequential optimal configuration.
2. Test `(eta_inicial, decaimiento_eta)` as a Cartesian product of their candidate lists.
   - Use the same 3 seeds.
   - Compare the best joint combination’s mean QE against the current configuration’s mean QE.
   - Adopt the joint values only if the mean QE is lower.
3. Test `(radio_inicial_relativo, decaimiento_radio)` in the same way, using the configuration after step 2.
4. Do not test any other pair.
5. Save both coupling experiments in `resultados/ej1/kohonen_sweep/sweep{k}/acoplamientos/`.
6. Record the baseline QE, joint best QE, selected values, and adoption decision in `docs/decisiones.md`.
7. Write the adopted values to `config_optima.toml`.

If a joint result is not better, keep the sequential values.

### 6.5 Sweep visualizations

Generate options A and B from the same step CSVs. Option C is disabled by default for legibility; its code remains available but is not generated by the real sweep.

- **Option A — `figuras/opcion_a/`:** one figure per step plus `fig_progreso.png`.
  - Numeric parameters: line plot of mean QE, ±1 std error bars, individual seed dots.
  - Categorical parameters: bar chart with error bars and seed dots.
  - The selected value is marked by underlining its x-axis tick label; no vertical reference line is drawn.
  - Summary: cumulative QE after each sequential step.

  - A separate dashboard for the two coupling heatmaps.
  - Compact titles, generous spacing, no overlapping labels; seed dots only if they do not add visual noise.

# Plan — TP4, Ejercicio 1.1: Exploración y representación

## Objetivo

Realizar un Análisis Exploratorio de Datos (EDA) y un Análisis de Componentes
Principales (PCA) sobre `datos/creadores.csv`, siguiendo la consigna del TP4 y
las fórmulas del capítulo 13 de `artif-eng.pdf` (pp. 115-119).

El resultado principal es el script `src/ej1/eda-pca.py`, que debe permitir
elegir por línea de comandos el porcentaje mínimo de varianza total a conservar.

## Referencias

- Consigna: `docs/context/consigna/SIATP42026.pdf`.
- Teoría de PCA: `docs/context/consigna/artif-eng.pdf`, pp. 115-119.
- Notas personales: `docs/context/gusslop.md`.

## Datos

- `datos/creadores.csv` tiene 50 filas y 33 columnas.
- 2 columnas identifican al creador: `creator_id` y `name`.
- 31 columnas son variables numéricas.
- No hay valores nulos, IDs duplicados ni columnas constantes.

## Variables que se excluyen del PCA

| Variable | Motivo |
|---|---|
| `price_ars` | Duplicado exacto de `price_usd × 1500`. |
| `estimated_argentina_reach` | Derivada de `average_reach × argentina_audience_pct / 100`. |
| `total_engagement_per_1000` | Suma exacta de likes, comentarios, guardados y compartidos. |
| `organic_posts_pct` | Complemento exacto de `sponsored_posts_pct` (suman 100). |

`total_engagement_per_1000` se conserva en el EDA como referencia de engagement,
pero no entra al PCA para no contar dos veces la misma información.

## Variables que se conservan

Se conservan las **cuatro categorías de tópico** y las **cuatro categorías de
contenido**. Aunque cada grupo suma 100 y genera una dependencia lineal, se
prefieren mantener completas para que el problema se entienda a primera vista.

Consecuencias:

- Quedan **27 variables** para el PCA.
- La matriz de correlación tiene **rango 25**.
- Aparecen **dos autovalores nulos** (uno por cada grupo que suma 100).
- El script detecta y reporta esos autovalores, y los excluye del conteo de
  componentes. Las cargas de las 27 variables se conservan e interpretan.

## EDA

1. Estadísticos descriptivos: cantidad, media, desvío muestral (`ddof=1`),
   mínimo, cuartiles, mediana, máximo, asimetría y curtosis.
2. Valores faltantes, IDs duplicados, columnas constantes y outliers por regla
   de 1,5 × IQR. Los outliers se reportan, no se eliminan.
3. Histogramas de todas las variables numéricas.
4. Matriz de correlación de Pearson y listado de los pares con mayor `|r|`.
5. Correlación de cada variable con `followers`, `total_engagement_per_1000` y
   `price_usd`. Esto ayuda a responder qué variable funciona como proxy de
   alcance, de engagement y de precio.
6. Identificación de bloques de variables: tamaño/alcance, engagement,
   audiencia, comercial, tópico, contenido y formato.

## PCA

Se implementa con NumPy, sin scikit-learn:

```text
z_ij = (x_ij - x̄_j) / s_j
S = ZᵀZ / (n - 1)
S v_k = λ_k v_k
ratio_k = λ_k / Σλ
q = mínimo q tal que Σ(k=1..q) ratio_k >= umbral
Y = Z V_q
```

Decisiones:

- Se estandarizan las variables porque las escalas son muy distintas
  (seguidores, porcentajes, dólares, segundos).
- Se usa la matriz de correlación, equivalente a la covarianza de las variables
  estandarizadas.
- Se usa `n - 1` para la covarianza muestral, igual que la definición de
  varianza muestral de la teoría.
- Los autovalores y autovectores se obtienen con `numpy.linalg.eigh`.
- PC1 se orienta para que `followers` tenga carga positiva. Las demás
  componentes se orientan para que su carga de mayor valor absoluto sea
  positiva. El signo es arbitrario, pero se fija para que los gráficos sean
  reproducibles.
- El umbral se recibe por parámetro. Valor por defecto: `0.95`.
- Se comparan los umbrales `0.90`, `0.95` y `0.99`.

Resultados con las 27 variables:

| Umbral | Componentes | Varianza acumulada |
|---:|---:|---:|
| 90% | 10 | 91,53% |
| 95% | 13 | 95,63% |
| 99% | 18 | 99,11% |

Interpretación:

- PC1 (49,71%): tamaño, alcance y profesionalización. Correlaciona
  aproximadamente 0,87 con `followers` y con `price_usd`.
- PC2 (9,19%): arte/showcase contra audiencia argentina/perros.
- PC3 (7,00%): publicaciones patrocinadas y fútbol.
- PC4 (5,83%): maquillaje contra fútbol.

La advertencia importante para la parte 3 es que PC1 se parece mucho a
`followers`; un índice basado solo en PC1 no necesariamente mide engagement por
dólar.

## Interfaz del script

```bash
python src/ej1/eda-pca.py --varianza 0.90
python src/ej1/eda-pca.py --varianza 0.95
python src/ej1/eda-pca.py --varianza 0.99
```

- `--varianza` debe ser una fracción en `(0, 1]`.
- El script solo lee `datos/creadores.csv`.
- El script escribe únicamente en `resultados/ej1/`.
- No hay pasos aleatorios, por lo que no hace falta semilla.
